训练规则定制

底层词库和基础反馈规则始终生效。你可以在上面叠加个人化的训练目标和规则。

底层系统规则 锁定
14 条实时反馈规则（重复检测 / 结论缺失 / 自问自答 / 听众视角 / 前后矛盾 / 时间感知 / 金句捕捉 / 类比检测 / 抽象→具象 / 主题漂移 / 立场模糊）
词库高亮（笼统词 / 填充词 / 犹豫词）
完整报告模板（总评 / 亮点 / 逐句编辑 / 用词替换表 / 行为模式 / 数据）
面试复盘底层维度 锁定
STAR 结构诊断（情境 / 任务 / 行动 / 结果 逐项打分）
面试雷区检查（抢功劳的"我们" / 成果没量化 / 抱怨前司 / 答非所问 / 缺乏思考深度）
面试官视角（第一印象 / 追问预测 / 综合评分）+ 措辞与表达状态分析
表达措辞指标（弱化表达率 / 积极词次数 / 弱化词次数 / 填充词频率）
积极词识别（热情 / 专注 / 从容 / 笃定 / 专业 / 协作等，用来判断热情和主动性）
弱化词检测（可能 / 也许 / 我觉得 / 应该 / 好像等，并给出更确定的替代表达）
我的训练目标 可编辑

你现阶段最想改善的表达问题是什么？AI会据此调整反馈优先级。

看示例
我现在最大的问题是：
1. 说话太散，经常跑题，一段话说完别人不知道我想表达什么
2. 口癖「然后」「就是」太多，听起来不专业
3. 描述事情总是用笼统的词，比如「很好」「挺不错的」，缺少具体画面
自定义触发规则 可编辑

格式：触发条件 → 输出什么提示（跟底层14条规则一起生效）

看示例
- 连续说了两个「非常」→ 「换个程度词」
- 出现「怎么说呢」→ 「别绕，直说」
- 讲了一个观点但没给原因 → 「为什么？」
- 用了英文但没翻译 → 「给个中文」
我想要的表达风格 可编辑

描述你理想中的说话方式，AI会在反馈时以此为标准。

我的口癖补充 可编辑

你自己特有的口癖/高频词，底层词库没覆盖到的。

我在面什么岗 可编辑

目标岗位、行业、级别，以及你最想通过练习拿下的目标。复盘会据此调整评价标准。

看示例
我在面产品经理岗位（2年经验，目标中厂）：
1. 我想讲清楚每个项目里"我"到底做了什么决策，而不是团队做了什么
2. 我讲成果时总是很虚，想练到每个成果都有数据
3. 被问到失败经历时容易慌，想准备得更好
复盘重点关注 可编辑

你希望面试官视角的复盘特别盯住哪些方面？可以指定弱化表达、积极词、回答结构等指标，会追加到复盘要求里。

看示例
- 我最大的毛病是讲成果不给数字，请每次都揪出来并帮我补一个量化版本
- 我习惯用"我们"，请帮我把该说"我"的地方标出来
- 帮我判断措辞是否明确，特别是「可能」「我觉得」「应该」这类弱化词
- 帮我看积极词是否太少，回答有没有体现主动性、热情和胜任感
- 帮我判断每段回答有没有正面回答问题，还是在绕
